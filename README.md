## Run locally
Open `index.html` directly or use VS Code Live Server.

## GitHub deployment
```bash
git init
git add .
git commit -m "Upgrade Support.SEEF portfolio to V4"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/support-seef-portfolio.git
git push -u origin main
```

Then enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / root**.
